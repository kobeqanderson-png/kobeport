# Kobe Anderson — open research portfolio

Static portfolio for https://kobeport.vercel.app/.

The site presents my research identity, public-beta projects, practical fabrication guidance, and opportunities for collaboration. Project claims distinguish implementation from validation.

## Preview

```bash
python -m http.server 8000
```

Open http://localhost:8000. No build step or JavaScript framework is required.

## Files

- `index.html`: portfolio and project introductions.
- `styles.css`: responsive layout and accessible focus states.
- `assets/`: selected original portfolio screenshots, extracted from the previous embedded images.
- `guides/3d-printing-for-science.html`: practical prototype-development guide.
- `guides/prototype-record.md`: reusable record of an actual prototype and its tests.

## Content updates

Keep demonstrations, user reports, and independent checks distinct. Add quantitative claims only with a reproducible source. Do not link the live MobileDLC study workspace as a public sandbox. Keep the beta documentation in MobileDLC and NeuroPipe-SABV aligned with site descriptions.

This portfolio remains in the existing repository and Vercel hosting workflow. Review the branch before merging; the repository's deployment settings determine whether a merge redeploys the live site.
